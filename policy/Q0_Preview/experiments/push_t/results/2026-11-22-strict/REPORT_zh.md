严格组只提供冻结官方 description，不附加 scoring、原任务卡、参考文件、预写操作建议或历史任务探测经验。原始观测在写盘、哈希、SSH 传输前清理归位评分阈值和派生判定；Python 读同一份清理后数据，未知字段拒绝。固定桌面高度保护及 CuRobo 桌面障碍物也被禁用。

保留当前 RGB、机器人本体状态与已观测初始位姿、相机标定、静态机器人几何、通用投影/三角测量/IK、动作执行反馈与预算；不返回物体真值、分割/深度、reward 或 success。每局只带本局生成的历史，评分器在模型外运行。详细边界、代码入口和原始证据见 [审计说明](../../STRICT_AUDIT_zh.md)。

## 模型与评测协议

日本 VPS 执行 agent，单卡 RTX4090 仿真与控制位于 Slurm 作业 1854993。使用订阅认证的 Codex CLI、gpt-6.2-sol，全部实际完成回执请求 Fast 并确认为 priority，无付费 API 回退。规划 xhigh、检查点 low。原生文件/Shell/搜索/MCP/子 agent 禁用；Python 在无网络沙箱中执行。CLI 的通用权限/模式说明逐字审阅并由哈希白名单约束。

每局最多 600 控制步、25Hz（24秒仿真控制时间），100计划；检查点60秒、单局墙钟10800秒、单轮3600秒。冻结基线默认25局，本实验扩展至50局，不属于官方默认25局协议的成绩，也不是官方Q0所用模型的数值复现。

原始组布局0–28使用Standard、29–49使用Fast；旧official_only和严格组全部Fast。旧实验的GPU共享、暂停及迁移与新单卡实验不同，运行时间和硬件阶段不完全一致；Fast21配对子集仍不能消除全部混杂因素。
